# pii-proxy

Локальный прокси между Claude Code и API (`ANTHROPIC_BASE_URL`): маскирует ПДн в запросе
через `pseudonymizer`, восстанавливает их в ответе. Настройки и порты - `deploy/env.example`.
Тесты: `bun test`, типы: `bun run typecheck`.

## Вложения: PII_PROXY_IMAGE_POLICY

| Значение | Что делает |
|---|---|
| `mask` | image и PDF-документы base64 уходят в `media-masker` (OCR, закраска ПДн, пикселизация лиц); по умолчанию, если задан `MEDIA_MASKER_URL` |
| `strip` | блок заменяется текстом-заглушкой (по умолчанию без `MEDIA_MASKER_URL`) |
| `reject` | любое вложение - 422 |

При `mask` нужны `MEDIA_MASKER_URL` и `MEDIA_MASKER_API_TOKEN` (без них прокси не стартует),
`MEDIA_MASKER_TIMEOUT_MS` (120 с).

- `image` base64: данные и `media_type` заменяются закрашенной перекодированной картинкой.
- `document` PDF base64: с текстовым слоем - блоками `text` (по странице), которые дальше
  проходят обычное маскирование токенами и вторую линию `/check`; скан - блоками `image`
  с закрашенными страницами. `title` документа становится первым text-блоком;
  `cache_control` переносится на последний блок замены.
- `source.type` не base64 (url, file) и документы не PDF - 422: проверить содержимое нельзя.
- media-masker отказал по файлу (413/422) - 422 с кодом причины в журнале; недоступен,
  таймаут, 5xx - 503, upstream не вызван (fail closed).
- Результат кэшируется по sha256 данных (бюджет 64 МБ base64, вытеснение давних): картинки
  истории не гоняются через OCR на каждом запросе, байты одинаковы - кэш промпта Anthropic цел.
  После перезапуска прокси кэш пуст, OCR детерминирован, поэтому байты те же.
- Порядок обхода и нумерация токенов не изменились: текст PDF встаёт на место документа.
