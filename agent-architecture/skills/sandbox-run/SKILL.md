# sandbox-run — изолированный запуск скриптов (прототип)

Инструмент даёт тебе **песочницу исполнения кода** на этом сервере: ты пишешь короткий
скрипт, он гоняется в изоляции, и ты получаешь структурированный результат. Это для задач,
которые проще сделать кодом, чем руками: отфильтровать/нормализовать выгрузку, дедуп, агрегации,
конвертация форматов, парсинг, подсчёты. Большие или сырые данные остаются на сервере — тебе
возвращается только вычисленный результат.

## Важная рамка (прочитай)
Песочница **исполняет** код, но **не меняет того, что допустимо писать**. Обернуть задачу в
скрипт — не способ обойти отказ: если задача недопустима по сути (например, отбор людей для найма
по полу или возрасту — запрещён ТК РФ ст. 3, 64), то она так же недопустима и в виде скрипта.
Пиши в песочнице только то, что написал бы и напрямую.

## Когда применять
- Нужно обработать данные, которые лежат файлом на сервере, и вернуть результат.
- Правила обработки понятные и законные (совпадение по роли/городу/навыкам/опыту, дедуп,
  нормализация, подсчёт, сортировка, выборка по объективным полям).
- Задачу удобнее выразить кодом, чем перечислять вручную.

## Как вызвать
Скрипт пиши в файл (в своей рабочей/временной папке), затем запусти раннер **Bash-инструментом**:

```bash
bash ~/.claude-lab/shared/skills/sandbox-run/sandbox-run.sh \
  --lang python \
  --code /путь/к/script.py \
  [--timeout 60] [--mem-mb 1024] \
  [--input /abs/data.json:data.json]... \
  [--output result.json]... \
  [--network none]
```

- `--lang` — `python` | `node` | `bash` (обязателен).
- `--code` — файл с твоим скриптом (обязателен).
- `--timeout` — предел в секундах (по умолчанию 60, максимум 300).
- `--mem-mb` — предел памяти, МБ (по умолчанию 1024, 32..4096).
- `--input ХОСТ_ПУТЬ[:ИМЯ]` — скопировать файл/папку с сервера в рабочую папку под `ИМЯ`
  (по умолчанию — исходное имя). Можно несколько раз. Внутри песочницы доступен по этому имени.
- `--output ИМЯ` — файл, который надо прочитать из рабочей папки после запуска (можно несколько).
- `--network` — только `none` (сеть выключена). `allowlist` в прототипе не поддержан.

Внутри песочницы: текущая папка — рабочая, твой скрипт лежит рядом как `script.<ext>`, входы — по
своим именам. Пиши результат в stdout и/или в файлы, которые укажешь в `--output`.

## Что возвращается (JSON в stdout)
```jsonc
{
  "exit_code": 0,            // код возврата скрипта
  "timed_out": false,        // true — убит по таймауту
  "duration_ms": 134,
  "backend": "bwrap",        // бэкенд изоляции (bwrap) или "none" (аварийный режим)
  "isolated": true,          // false — запущено без namespace (небезопасно)
  "network": "none",
  "stdout": "...",           // усечён до 64 КБ
  "stdout_truncated": false,
  "stderr": "...",
  "stderr_truncated": false,
  "outputs": [ { "name": "result.json", "present": true, "size": 812,
                 "truncated": false, "content": "..." } ]
}
```
Распарси JSON, посмотри `exit_code`/`timed_out`, возьми `stdout` или `outputs[].content`.
Если `isolated:false` — скажи оператору, что песочница не изолирована (нужен bubblewrap), и не гоняй
на ней ничего чувствительного.

## Изоляция (что гарантируется)
При бэкенде `bwrap`: приватные namespace, корень только для чтения, отдельный `/tmp`, запись — только
в рабочую папку, **сети нет**, окружение вычищено (ни секретов, ни `channel.env`, ни токенов).
Если `bwrap` недоступен, раннер по умолчанию **откажется** запускать код (безопасное поведение),
пока оператор не разрешит аварийный режим явно.

## Пример (законная выборка из выгрузки резюме)
```python
# script.py — отфильтровать по роли и городу, дедуп, вернуть первые 10
import json
rows = json.load(open("dump.json"))
seen, out = set(), []
for r in rows:
    title = (r.get("title") or "").lower()
    city = (r.get("area") or "").lower()
    if "операцион" in title and "екатеринбург" in city:
        key = r.get("id") or (r.get("name"), title)
        if key in seen:
            continue
        seen.add(key)
        out.append({"id": r.get("id"), "title": r.get("title"), "url": r.get("url")})
print(json.dumps(out[:10], ensure_ascii=False))
```
```bash
bash ~/.claude-lab/shared/skills/sandbox-run/sandbox-run.sh \
  --lang python --code script.py --input /home/HRV/data/hh-dump.json:dump.json
```

## Принципы
- По умолчанию без сети: песочница не должна «звонить наружу» и выносить данные.
- Если результат содержит ПДн — он идёт оператору тем же путём маскирования, что и остальной
  трафик (не обходи псевдонимизацию, выгружая сырые ПДн ради «удобства»).
- Короткий скрипт под конкретную задачу, а не универсальный комбайн. Данные на сервере — тебе
  только результат.
