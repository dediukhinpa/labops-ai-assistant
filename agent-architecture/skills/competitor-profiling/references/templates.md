# Competitor profile templates

## Full profile
```markdown
# [Competitor] — Competitor Profile
**URL**: … **Generated**: [date] **Depth**: quick scan | deep profile

## At a glance
| Metric | Value |
|---|---|
| Tagline | [from homepage] |
| Founded / HQ / Team size / Funding | … |
| Domain rank | [client's SEO export] |
| Est. organic traffic | [monthly] |
| Referring domains / Organic keywords | … |

## Positioning & messaging
Primary value proposition: "[exact headline]" + "[subheadline]"
Target audience: … | Positioning angle: … | Messaging themes (with source page): …

## Product & features
Core capabilities · Notable differentiators · Integrations (count + key) · Product direction signals

## Pricing
| Tier | Price | Key inclusions |
Billing: … | Free trial: … | Notable: per-seat / usage-based / hidden costs

## Customers & social proof
Named customers · Industries · Case study themes · Review ratings (G2, Capterra) with counts

## SEO & content strategy
Traffic, top-10 keywords, traffic value · Top organic pages (URL — keyword — est. traffic) · Blog frequency, content types, focus · Referring domains, top referrers, trend

## Strengths & weaknesses
Strengths (with evidence) · Weaknesses (with evidence)

## Competitive implications for [client]
Where they're stronger · Where we're stronger · Opportunities · Threats

## Raw data sources
Pages read (with dates) · SEO export source and date · Review data source and date
```

## Positioning map
Pick the two most relevant axes:
| Market | X axis | Y axis |
|---|---|---|
| SaaS tools | Simple → Complex | Cheap → Expensive |
| Developer tools | Low-code → Code-first | Individual → Team |
| B2B platforms | SMB → Enterprise | Point solution → Platform |
| Content tools | Template-driven → Custom | Self-serve → Managed |

```
                 [Y high]
                    │
   [Competitor A]   │   [Competitor B]
 ───────────────────┼───────────────────
   [X low]          │          [X high]
   [Us]             │   [Competitor C]
                 [Y low]
```
Add interpretation: what the map reveals and where the whitespace is.

## Competitive SWOT (per competitor, relative to the client)
```markdown
## SWOT: [Competitor] vs [Us]
Strengths (theirs): where they genuinely outperform us
Weaknesses (theirs): where they fall short, with evidence
Opportunities (ours): gaps in their offering, segments they ignore, messaging they miss
Threats (theirs): what they're improving fast, overlapping features, market moves
```
