# Прокси на своём сервере для Donut Browser

Donut Browser на вашем компьютере ходит в сеть через ваш сервер: сайты видят адрес сервера,
а не домашний. Прокси — это Squid с входом по логину и паролю. Ставит его `install.sh`.

## Установка на сервере

Прокси нужен ДО аккаунта Claude (через него аккаунт и регистрируют), поэтому его можно
поставить отдельно, не начиная остальную установку:

```bash
bash install.sh --proxy-only
```

Или в составе полной установки: `SETUP_PROXY=1 bash install.sh`. По умолчанию шаг выключен —
он открывает порт 3128 наружу.

Что делает шаг (`orchestration/lib/proxy-install.sh`):

- ставит `squid` и `apache2-utils`;
- пишет `/etc/squid/squid.conf` (прежний конфиг сохраняет как `*.labops-bak-<время>`);
- создаёт пользователя `labops` и **случайный** пароль, хэш кладёт в `/etc/squid/labops-passwd`;
- записывает адрес, порт, логин и пароль в `~/proxy-credentials.txt` (права 600) — **в вывод
  установщика пароль не печатается**; прочитать: `cat ~/proxy-credentials.txt`;
- открывает порт в `ufw`, если он включён;
- проверяет: без пароля прокси отвечает 407, с паролем пропускает.

Повторный запуск безопасен: пароль и конфиг остаются, Squid перезапускается только при смене конфига.

| Переменная | Что делает |
|---|---|
| `LABOPS_PROXY_PORT` | порт (по умолчанию 3128) |
| `LABOPS_PROXY_USER` | логин (по умолчанию `labops`) |
| `LABOPS_PROXY_ALLOW_FROM` | пускать на порт только с этого IP/подсети (правило `ufw`) |

## Ограничения (честно)

- **Пароль идёт по сети открытым текстом.** Между компьютером и прокси трафик HTTP-прокси не
  шифруется (сами сайты по HTTPS остаются зашифрованы). Поэтому: не пользуйтесь прокси из
  публичных Wi-Fi и по возможности ограничьте доступ своим домашним IP —
  `LABOPS_PROXY_ALLOW_FROM=<ваш IP> bash install.sh --proxy-only`. Ранее открытое правило `ufw`
  для всех сам скрипт не удаляет: `sudo ufw status numbered`, затем `sudo ufw delete <номер>`.
- **Страна сервера** должна быть в [списке поддерживаемых Anthropic](https://www.anthropic.com/supported-countries).
  Если сервер в закрытом регионе, проверка в конце установки покажет предупреждение (ответ 403).
- Если порт закрыт в панели хостинга (облачный файрвол), `ufw` этого не видит — откройте его там.
- Прокси работает на Linux с apt и systemd (Ubuntu/Debian). Другие системы скрипт отвергает.

## Donut Browser

Проект: [donutbrowser/donutbrowser](https://github.com/donutbrowser/donutbrowser), лицензия AGPL-3.0.
Движок один — Wayfern (на базе Chromium); при первом запуске нужно принять его условия, после
чего Donut один раз скачивает движок. Аккаунт не нужен.

Сборки в релизе v0.36.0 (на 05.11.26):

| ОС | Что есть | Чего нет |
|---|---|---|
| macOS | DMG для **Apple Silicon**; `brew install --cask donut` | сборки для Intel Mac |
| Windows | установщик `x64-setup.exe`, portable `x64-portable.zip` | сборки для ARM |

### Настройка прокси в Donut

1. Откройте страницу **Network** (Cmd/Ctrl+N), вкладка **Proxies**, кнопка **New proxy**.
2. Тип **HTTP**; Host — адрес сервера, Port — 3128; логин и пароль из `~/proxy-credentials.txt`.
3. Кнопкой проверки рядом с прокси убедитесь, что внешний IP — адрес сервера, а страна — нужная.
4. Страница **Profiles** → **New** → имя профиля → в поле **Proxy / VPN** выберите прокси → **Create**.
5. Запустите профиль. Для регистрации Claude включите в **Settings → Privacy** опцию
   **Block launches without a proxy or VPN**: профиль не откроется с вашего домашнего IP.
   Режим WebRTC оставьте **Automatic** или **Proxy exit only**.

Названия кнопок взяты из документации Donut (donutbrowser.com/docs/proxies и /docs/install) и
могут измениться в новых версиях.

## Чек-лист проверки на macOS и Windows

Установку и работу на этих системах из репозитория проверить нельзя — это делает человек.
Отметьте результат для каждой системы:

- [ ] Скачивание установщика (macOS: DMG или `brew`; Windows: `x64-setup.exe`) проходит без ошибок
- [ ] Первый запуск: приняты условия Wayfern, движок скачался
- [ ] macOS: приложение открывается (нет окна «нельзя открыть» от Gatekeeper); если есть — как обошли
- [ ] Windows: SmartScreen не блокирует; если блокирует — как обошли
- [ ] Прокси создан (тип HTTP, логин/пароль), проверка показывает IP сервера
- [ ] Профиль с этим прокси открывает https://browserleaks.com/ip и показывает IP сервера
- [ ] https://browserleaks.com/webrtc не показывает домашний адрес
- [ ] https://claude.ai открывается из профиля
- [ ] Без пароля (пустые поля) профиль не выходит в сеть (получает 407)

Что известно на сегодня: в документации Donut нет сведений про Gatekeeper, SmartScreen,
минимальные версии macOS и Windows — эти пункты можно закрыть только пробным запуском.
